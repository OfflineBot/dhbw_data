## Project Overview

DHBW data science assignment (WDS125) analyzing airline passenger satisfaction. The main work lives in `airline_satisfaction.ipynb`, a single Jupyter notebook covering data cleaning, exploratory analysis, and a Random Forest classifier.

**Dataset:** `data/airline.csv` — 103,907 records × 13 features (see `data/column_description.txt` for column definitions). After cleaning: 103,902 × 11 features.

## Running the Notebook

```bash
jupyter notebook airline_satisfaction.ipynb
# or
jupyter lab
```

Run cells sequentially from top to bottom. There is no build system, test suite, or linter.

## Notebook Structure

The notebook has three main sections:

1. **Data Cleaning** — loads CSV, removes duplicates, fixes invalid "Leg room service" values, fills missing "Age" entries, drops `Customer ID` and `isPilot` columns.
2. **Data Exploration** — satisfaction distribution, class distribution, age histogram, distance boxplot by satisfaction, correlation heatmap, scatter plot, outlier boxplots. Figures are saved to `figures/`.
3. **Predictive Modeling** — one-hot/ordinal encoding of categoricals, 80/10/10 train/val/test split, `RandomForestClassifier`, evaluation with classification report and confusion matrix (~86% accuracy).

## Key Dependencies
